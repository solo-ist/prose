Prose theme

A theme for the Prose app that finally matches the marketing brand. Paper-warm cream on near-black, hairline borders, a single gold accent reserved for live state and emphasis. Light mode is paper, not pure white. Body and chrome use IBM Plex Mono at light weights; emphasis swaps to Fraunces italic — the brand's most identifiable type move.
