Welcome to Prose.

A free, open-source markdown editor for the AI era.

Local first. Plain .md and .txt on disk.
Optional AI. It doesn't strive to write for you.
Quick setup. Skip anything. Change it later in Settings.

AI writing assistance

Choose how Prose works. You can switch any time in Settings.

Add your Anthropic key

Prose uses your own key. It's kept in the macOS Keychain and only ever sent to Anthropic.

Starts with sk-ant-. Create one at console.anthropic.com. Checking with Anthropic… Key works. Saved to Keychain. That isn't an Anthropic key. It should start with sk-ant-.
No key yet? Skip this. The assistant waits until you add one in Settings → AI ⌘,

Connect Claude

Optional. Both live in Settings → Integrations too.

Claude Skill Teaches Claude to outline, read and propose edits to Prose documents. Upload it on claude.ai under Customize → Skills.
Claude Desktop Adds the Prose MCP server, so Claude Desktop can read and edit the document you have open.

Open .md files in Prose

macOS doesn't let apps set this themselves. It's four clicks in Finder.

  1. 1Right-click any .md file
  2. 2Get Info ⌘I
  3. 3Under Open with, pick Prose
  4. 4Click Change All…
