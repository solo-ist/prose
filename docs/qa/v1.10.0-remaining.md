### P3 (#891) — Suggesting mode (5 left)

On the dev server (`qa/dev`), with a markdown file you can look at outside Prose (in Finder's Quick Look, or `cat` in a terminal). Suggesting mode is off until you turn it on, one tab at a time.

> **What Suggesting mode doesn't track yet.** It tracks text *within* a paragraph. Starting a new paragraph (Enter), joining two (Backspace at a paragraph's start), pasting or deleting across paragraphs, changing table rows, and typing in a code block are **refused with a message** asking you to turn Suggesting off for them; nothing happens to the text. Formatting (bold, links, headings, lists) applies directly and is not tracked. Source mode is unavailable while Suggesting is on or while tracked changes are pending.

**Typing and deleting**

- [x] One count for everything waiting on you. With a tracked change pending, have an agent (or the chat) propose an edit with `suggest_edit`: the status bar shows a single **2 suggestions**, not two separate counts. Hovering it splits the number (1 tracked change, 1 suggested edit) and clicking it opens Quick Review, which counts the same two (1/2).

**Agents (MCP)**

From Claude Code, Claude Desktop or Codex connected to the dev build (setup B):

- [x] Ask it to `suggest_insert` a phrase after some words of a paragraph, and to `suggest_delete` a phrase: both show in the text (underlined, struck) in the agent's own colour, named for the connection in Activity and Quick Review. Your caret doesn't move.
