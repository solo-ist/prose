# Prose 1.9.0 — Mac App Store QA (TestFlight)

The App Store serves **1.6.5**, so this build is the first App Store build since 1.6.5. It is also the first to run
1.8.0's and 1.9.0's main-process changes inside the App Sandbox. The MAS-flagged checks without the sandbox already
pass: `e2e/electron.mas-gates.spec.ts` and `e2e/electron.mas-home.spec.ts` (PRs #1224, #1225). This script covers
what only the sandbox decides, and what an App Store user sees.

**Build:** `main` after #1224, #1225 and #1226 merge → `npm run build:mas` on the signing machine → the checks in
`/release mas` (version `1.9.0`, build `34`, entitlements) → Transporter → TestFlight. Tick in Prose, add notes under a
box as a `>` line.

## 1. Upgrade from the App Store version

Start from the App Store's 1.6.5 with your normal data: a project folder, a favorite, an API key, a document with
comments and an image. Then install 1.9.0 from TestFlight over it.

- [ ] Launch: no onboarding. The "What's new in Prose 1.9.0" window opens once and ends with "Since the last App
      Store version". It says nothing about sharing, Claude Desktop, MCP or sign-in, and has no update button.
- [ ] Got it, then quit and relaunch: the window does not come back.
- [ ] Settings → LLM: the API key is still there and Test passes; a chat message streams.
- [ ] Explorer: the project and the favorite still open their folders without asking for access again.
- [ ] The document with comments: comments and AI highlights are on their text.
- [ ] **An image in a document inside the project folder renders.** (#1223: on the unfixed code every image
      outside the app container was refused.)
- [ ] The Dock icon is Pilcrow and follows Light / Dark / Clear / Tinted (macOS 26).

## 2. Fresh install

After section 1, quit Prose and delete `~/Library/Containers/ist.solo.prose`. This removes every App Store Prose
setting, key and bookmark on this Mac; your documents are untouched. Then launch.

- [ ] Onboarding shows five steps, 1 / 5 to 5 / 5: Welcome, AI and privacy, API key, Default editor, Done. There is
      no Claude step, and no "App Store build" caption in the header.
- [ ] API key: a bad key shows the format error; a real key verifies.
- [ ] Done lands on the home screen (Start Writing). New Document makes one tab.
- [ ] Crash reports: the checkbox started unchecked; if you ticked it, Settings → General shows Error Reporting on.

## 3. What the sandbox decides

- [ ] **Open (⌘O) on a fresh install starts in your Documents folder**, the real one, not an empty hidden folder.
- [ ] Open a file from another folder, then ⌘O again: the dialog starts in that folder. Quit, relaunch, ⌘O: still
      that folder.
- [ ] Save As (⌘⇧S) and Export HTML start in a sensible folder and write where you chose.
- [ ] Explorer, inside a granted folder: rename, Duplicate, move to Trash, cut and paste into a subfolder, drag a
      file onto `..` from a subfolder.
- [ ] Explorer, at the top of the granted folder: dragging a file onto `..` does nothing (no highlight, no move).
      Clicking `..` asks for folder access.
- [ ] Edit an open file in another editor, return to Prose: a clean tab reloads; a tab with unsaved edits shows the
      conflict prompt.
- [ ] Autosave (Settings → Editor) writes the file.
- [ ] Open a single `.md` from Finder (Open With → Prose) whose image sits next to it: the document opens. The image
      may stay blank because the sandbox grants the file, not its folder. Note what you see.
