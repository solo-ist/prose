**Result (2026-11-04):** the pass was run and ticked in `v1.9.0-editor-state.md` §3–§7 instead (81 of 82, one open: Save As #1169; one accepted note, four follow-ups #1179–#1182 in its "Misc triage (2026-11-04)"). **How to tell you are in the right build:** ⌘O opens the picked file in a **new tab**, and a tab left in source mode is still in source mode when you switch away and come back.

**Setup, once.** Autosave **off** (Settings) until step 7. Three fresh markdown files in one folder, five or six paragraphs each: **A**, **B**, and **F**, where F starts with

```
---
title: F
tags: [a, b]
date: 2026-11-03
---

```

(a blank line after the closing fence; the file ends with a newline). A fourth file **C** can be anything. A shared document **S**, if you have one published, is for step 11. The chat needs the API key configured; every chat request below is in create mode unless it says suggest.

## 1 · Seed and switch

- [ ] **Seed A.** Select a sentence, add a comment, reply to it from the popover. Ask the chat to rewrite one paragraph and accept: the paragraph carries an AI highlight and an Activity entry. [1.1, 3.1]

- [ ] **Seed B.** The same: a comment (no reply) and an accepted rewrite. Each document shows only its own thread and its own highlight. [1.1, 3.1]

- [ ] **Twenty switches.** Alternate A → B → A ten times, some via the tab bar, some via the explorer, typing a few words outside the marked text on every visit. After the last switch: each document shows exactly its own thread (A's with the reply) and its own highlight on the AI's words; the caret and scroll come back where you left them; nothing is resolved; the status-bar comment count and the chat chip match the active tab. [1.1, 3.1]

- [ ] **Edit above a highlight.** In A, click at the end of a paragraph above the highlight, Backspace the last word leaving a trailing space, switch to B and back: the highlight still covers exactly the AI's words. [1.1]

- [ ] **Activity panel follows the tab.** Open the Activity tab in the chat sidebar, switch A → B → A: only the active document's entries, each time. [2.3]

- [ ] **Selection across tabs.** Select a sentence in A, switch to B without selecting anything, ask the chat to read the current selection: it reports no selection. Back to A, select again, ask: A's sentence. [7]

## 2 · Comment threads

- [ ] **Resolve and reopen.** Resolve A's thread from the popover: the highlight goes, the Activity panel files it under resolved. Reopen it from there (or the popover): the highlight is back on the same words. [3.2]

- [ ] **Delete the text, undo.** Select a commented sentence whole and delete it: the thread resolves itself (the count drops, Activity shows it resolved). ⌘Z: the text and the highlight are back and the thread is open again. [3.2]

- [ ] **Chat processes a thread.** Add a comment asking for a change, click Process in the popover (or "Review comments" in the chip): the model replies and/or resolves through its tools, and the reply shows in the thread. [3.3]

- [ ] **AI edit over a comment.** With a commented sentence, ask the chat to rewrite that paragraph and accept: the thread stays open, shown as anchor-lost in Comment Review; ⌘Z puts the highlight back. [3.3]

- [ ] **Comment Review panel.** Enter it from the status-bar count; resolve one thread (swipe or ↵), reply to another (⌘↵). Both show in the Activity panel and survive a tab switch. [3.3]

- [ ] **Delete a thread.** The trash icon in the popover: highlight and thread gone. (Step 10 checks it stays gone.) [3.2]

## 3 · AI highlights

- [ ] **Accept over an existing highlight.** Ask the chat to change one word of an already-highlighted sentence and accept: the rest of the sentence stays one highlight and one Activity entry, not one per word. [§2 triage]

- [ ] **Remove.** Hover an entry in Activity, click its X: the highlight leaves the text and the entry leaves the list. (Step 10 checks it stays gone.) [2.3]

- [ ] **Jump.** Click an entry's crosshair: the caret lands on its words; a dimmed (superseded) entry does nothing. [2.3]

- [ ] **Mark and unmark as AI.** Select plain text, use the selection toolbar's AI toggle: a highlight appears; toggle again: gone. Select the first half of an existing highlight and toggle: only the second half remains. [2.3]

- [ ] **Paste as AI.** Paste a sizable chunk of text, answer Yes to "mark as AI-authored": the pasted text is highlighted and listed. [2.3]

- [ ] **AI deletion marker.** Ask the chat to delete a paragraph and accept: an "AI Deletion" entry stays current (not dimmed) while you type elsewhere; its crosshair puts the caret where the paragraph was. [2.4]

## 4 · Source mode

- [ ] **Follows the tab.** In A, ⌘⇧E into source mode, click into the middle of a line, fold a heading with the gutter chevron. Click B (its rich editor shows), click A: still in source mode, the caret where you left it, the fold still folded. [5.1]

- [ ] **Both tabs in source.** Put B in source mode too; switch back and forth: each shows its own text and caret. ⌘⇧E B out without typing: B is not marked dirty. [5.1, 1.2]

- [ ] **Type, switch, exit later.** In A (source), add a line to a paragraph that has no highlight and change a word in a line above the marked text; switch to B, come back, ⌘⇧E out: both edits are there, and the thread and the highlight sit on their words. One ⌘Z removes the whole source edit at once with the marks still on their words; ⌘⇧Z brings it back with the marks intact. [5.2, 1.2, 2.2]

- [ ] **Edit the commented sentence in source.** ⌘⇧E in, change words inside the commented sentence, ⌘⇧E out: the thread is anchor-lost (open, no highlight), not resolved. [3.4]

- [ ] **Save in source mode.** ⌘⇧E in, type a line, ⌘S without leaving: the file on disk has the line; ⌘⇧E out: not dirty. [5.2, 6.2]

- [ ] **Shortcuts stay with CodeMirror.** In source mode, select a line, ⌘D, ⌘⇧E out: the rich document shows exactly the source text, nothing duplicated behind your back. [5.3]

- [ ] **Chat refused.** With A in source mode, ask the chat to edit A: the model is told the document is in source mode and nothing changes. ⌘⇧E out: edits work again. [5.3, 4.4]

- [ ] **Theme change.** In source mode with the caret mid-document, Settings → Appearance → switch the theme: the caret and the text stay put. [5.3]

- [ ] **Close in source mode.** Put C in source mode, type a line, switch to A, close C from the tab bar (Save if asked). ⌘⇧T: the line is in C. [5.2]

- [ ] **Toggles.** The toolbar button, the status-bar label, View → Toggle Source and ⌘⇧E each toggle the tab in front; after a switch the button's icon and the label follow the tab. [6.4]

## 5 · Frontmatter, dirty and saves

- [ ] **Edit a field.** In F, change `title`: the dirty dot at once. Change it back to the original value: the dot goes away without a save. [6.1]

- [ ] **Add a field.** "Add field", type a key and a value, Return twice: the row stays, nothing you typed is wiped mid-edit. ⌘S, close F, reopen it from the explorer: the field is there, keys in the order you saw. [6.1]

- [ ] **Non-text fields.** `tags` and `date` show locked (🔒); the other rows edit normally, and editing one row never resets another you are typing in. [6.1]

- [ ] **AI frontmatter suggestion.** Ask the chat (suggest mode) to suggest frontmatter for F: the overlay appears. Reject: nothing changes. Ask again, Accept: the rows update and F is dirty. Switch tabs with an overlay open and come back: the overlay is gone. [6.1]

- [ ] **Undo to clean.** In a saved document, type (dot), ⌘Z back to the saved text: the dot is gone; ⌘W takes no prompt (⌘⇧T to get it back). [6.2]

- [ ] **Type during a save.** In a large document, ⌘S and keep typing at once: the dot comes back; ⌘S clears it. [6.2]

## 6 · A chat turn stays with its document

- [ ] **Switch away mid-turn.** In A, ask the chat to rewrite two paragraphs. - [ ] **Stop is per document.** A turn on A, switch to B, a turn on B, Stop on B: B's stops, A's finishes. [4.1]

- [ ] **Close mid-turn, saved document.** ⌘S A, start a turn, close A mid-turn and Discard: A reappears in the tab bar in the background once the turn continues; click it: the later edits are there with highlights (the discarded early ones are not). [4.2]

- [ ] **Close mid-turn, untitled.** A new untitled document with a few paragraphs, start a turn, close the tab mid-turn (Discard): nothing lands anywhere else; the other tabs are untouched. [4.2]

- [ ] **Create a file from the chat.** In A: "Create a new document called Notes with an outline, then add a closing paragraph." The new file opens, the outline and the paragraph land in it (not in A), and its chat panel shows this conversation continuing. [4.3]

## 7 · Autosave

- [ ] **Auto, frontmatter only.** Settings → autosave Auto. In F, edit a value and stop typing: within about two seconds "saving…" flashes in the status bar and the file has the new value, the body bytes untouched. [6.3]

- [ ] **Auto, source mode.** In source mode on F, edit the title line and wait: the file updates while source mode is still open. [6.3]

- [ ] **Auto, switch mid-debounce.** Make B dirty. Type in A, switch to B within a second: A still saves (check the file) and B's dot stays. [6.3]
