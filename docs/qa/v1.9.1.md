# 1.9.1 QA

One block per PR of epic #1230 (https://github.com/solo-ist/prose/issues/1230). Tick in Prose; a note under a box is a finding.

## P1 (#1232): who made each record

On the dev server (`qa/dev`), any document.

- [ ] Settings → General shows **Your Name** and **Email (optional)**. Set a name, Save Changes.
- [ ] Select text, add a comment: the popover names you by that name; with the name cleared, it says "You".
- [ ] Reply in the popover: the reply carries your name too.
- [ ] Ask the in-app chat to comment on a paragraph: the comment says "Prose · <model>" (for example "Prose · Sonnet 5.5"), not "Prose" alone.
- [ ] From Claude Desktop (or another MCP client), add a comment: it says "MCP client".
- [ ] Have the chat suggest an edit: the suggestion popover shows "By Prose · <model>". Accept it: the AI highlight's tooltip and its Activity row name the same agent instead of a bare model id.
- [ ] Mark a selection as AI-written (selection popover): Activity says "Imported".
- [ ] Open a document you commented on before this build: your old comments show your name, old AI comments show "AI", and a share reviewer's comment shows their name (it used to say "you" when expanded in Activity).
- [ ] Quit and relaunch: every name above is still right.

## P2 (#1233): the review log

The log has no UI of its own until P4 (#1234) lists it in Activity, and agents read it through M4 (#890). These checks use the dev tools console (`PROSE_DEBUG=1`) or wait for P4.

- [ ] Ask the in-app chat to suggest an edit, give it feedback in the suggestion popover, then accept it. `__prose_tools.getReviewLog()` shows the suggestion as accepted (by you), with your feedback entry, and four events in order: proposed, feedback, accepted.
- [ ] Reject a suggestion, then press ⌘Z. The log shows it rejected and then reopened, and the rejection stays in the events.
- [ ] Delete the text a suggestion covers. The log shows it rejected by you.
- [ ] Comment, have the chat reply, resolve it. The log has added, replied and resolved, each with the right actor.
- [ ] Quit and relaunch: the log reads back the same.
