## M1 (#1235) — MCP protocol on the v2 SDK

Run against the dev window (port **9878**) before merge, or the installed app (port **9877**) after a release.
The token rotates on every launch until M2 (#1236), so re-read it after a restart.

```sh
PROFILE="$HOME/Library/Application Support/Prose Dev"   # installed app: .../Prose
TOKEN=$(cat "$PROFILE/mcp-auth-token"); PORT=9878        # installed app: 9877
```

- [ ] **Health and info.** `curl -s http://127.0.0.1:$PORT/health` → `{"status":"ok"…}`;
      `curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:$PORT/` shows the app version (1.9.x, not 1.0.0) and
      `protocolRevisions: ["2026-07-28","2025-11-25"]`.
- [ ] **Rebinding guard.** `curl -s -o /dev/null -w "%{http_code}\n" -H "Host: attacker.example" -H "Authorization: Bearer $TOKEN" -X POST http://127.0.0.1:$PORT/mcp`
      → `403`. The same with `-H "Origin: https://attacker.example"` instead of the Host header → `403`.
- [ ] **Two instances, two ports.** With the installed Prose and the dev window both running, each answers on its own
      port (9877 and 9878) with its own token; neither logs `Port … is already in use`.
- [ ] **Claude Code.** `claude mcp add --transport http prose-qa http://127.0.0.1:$PORT/mcp --header "Authorization: Bearer $TOKEN"`,
      then in Claude Code: "list my Prose tabs" → the tabs of that window. `/mcp` shows the server connected with
      10 tools. Remove it afterwards: `claude mcp remove prose-qa`.
- [ ] **Codex.** In `~/.codex/config.toml`:
      `[mcp_servers.prose_qa]` / `url = "http://127.0.0.1:9878/mcp"` / `bearer_token_env_var = "PROSE_QA_TOKEN"`,
      then `PROSE_QA_TOKEN=$TOKEN codex` → "read the active Prose document" returns its text. Remove the block afterwards.
- [ ] **Claude Desktop (stdio).** Settings → Integrations shows the MCP server needs an update (the bundled bridge
      changed); update, restart Claude Desktop, and ask it to list Prose tabs. Tool cards show titles ("List tabs").
- [ ] **A suggestion still lands for review.** From any client above: read the document, then suggest an edit to
      one paragraph → the suggestion appears in Prose for you to accept or reject.
