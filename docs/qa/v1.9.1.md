## P3 (#891) — Suggesting mode

On the dev server (`qa/dev`), with a markdown file you can look at outside Prose (in Finder's Quick Look, or `cat` in a terminal). Suggesting mode is off until you turn it on, one tab at a time.

> **What Suggesting mode doesn't track yet.** It tracks text *within* a paragraph. Starting a new paragraph (Enter), joining two (Backspace at a paragraph's start), pasting or deleting across paragraphs, changing table rows, and typing in a code block are **refused with a message** asking you to turn Suggesting off for them; nothing happens to the text. Formatting (bold, links, headings, lists) applies directly and is not tracked. Source mode is unavailable while Suggesting is on or while tracked changes are pending.

**Turning it on**

- [ ] Open a `.md` file. The status bar says **Editing**; the toolbar has a pen button. Click either: the status bar says **Suggesting** and the pen button is highlighted. Switch to another tab: it still says Editing there. Come back: Suggesting.
- [ ] Open a `.txt` file, a preview tab (single click in the explorer) or source mode: the switch is greyed out.
- [ ] Hover the pen button or the status bar switch: the tooltip says **Formatting changes apply directly**.
