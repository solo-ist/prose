# Inference Cooperative gateway captures (2026-10-19)

Raw responses from `https://gateway.inference.coop` on an individual member key, captured for
[`docs/issues/598/inference-coop-findings.md`](../../../../docs/issues/598/inference-coop-findings.md)
(spike #952). They contain no secrets: the key was sent as a header and is not in any file.
Use them as deterministic inputs for the chat-completions mapper and the normalized stream
protocol (#1075, #954).

| Prefix | What | Request shape |
|---|---|---|
| `p1-chat-tools-<model>.sse.txt` | streaming `POST /v1/chat/completions` with Prose's `suggest_edit` tool, `tool_choice: auto`, `stream_options.include_usage: true` | system prompt with one document node + "Fix the typo in node n1." |
| `p1b-chat-toolresult-*.sse.txt` | the second turn: assistant `tool_calls` + `role: tool` result | same |
| `p1r1-`, `p1r2-chat-tools-greenpt_glm-5.3.sse.txt` | reruns of the failing GreenPT tool call (`max_tokens` 400 / 2000) | same |
| `p2-messages-tools-<model>.sse.txt` | streaming `POST /v1/messages` (Anthropic format) with the same tool | `system`, `messages`, `tools[].input_schema` |
| `p2b-messages-toolresult-*.sse.txt` | Anthropic-format second turn (`tool_use` + `tool_result` blocks) | same |
| `p3-bodycap-<size>.resp.txt` | non-streaming, `max_tokens: 1`, a padded system message of 256 KB–1.5 MB on `greenpt/glm-5.3-flash` | body-cap probe |
| `p6-gen-<model>.sse.txt` | 700-token plain generation for throughput; shows reasoning consuming the whole budget on Tinfoil models | "Write a 500-word essay about lighthouses." |
| `p7*-<model>.sse.txt` | per-request thinking control: `reasoning_effort: "none"`, `chat_template_kwargs`, Anthropic `thinking` (dropped) | 150-word paragraph |

Request bodies were generated by a throwaway script (bodies are reconstructible from the table);
timings and the analysis summary are in the findings doc, §1, §4 and §9.
