# Prose v1.10.0

Any model, and every contribution has a name on it. Prose Agents now run on OpenAI as well as Anthropic, you can suggest changes yourself with Suggesting mode, and every comment, suggestion and AI edit records who made it.

## Models

- **OpenAI beside Anthropic.** Add an OpenAI key in Settings → LLM and pick a GPT model from the same list as the Claude models; the provider follows the model you pick. The status bar's model menu lists both.
- **One key per provider.** Each provider has its own key row with Test, Save and Clear. Keys are kept in the Keychain and used only by the app's main process.
- **Onboarding takes both keys.** A new install can verify an Anthropic key, an OpenAI key or both, and chat works straight after.
- **The OpenAI list is GPT-5.5 and newer**, limited to the models that can use Prose's tools. Any other model id can be typed under **Use custom model**.
- An OpenAI account with no credits now says so, instead of reading as "rate limited".
- Tab emoji still use your Anthropic key.

## Suggesting mode

- **Suggest instead of edit.** Click the pen button or **Editing** in the status bar. What you type is underlined, what you delete is struck through, and the file on disk keeps the original text until you accept.
- **One count for everything waiting on you.** The status bar shows a single suggestion count for your tracked changes and the AI's suggested edits; clicking it opens Quick Review.
- **Quick Review shows each change in its sentence**, so a deleted comma or an inserted word reads in context.
- **View controls.** The status bar's **All changes** menu can hide deletions or show the final text, and has Accept all and Reject all.
- Suggesting tracks text within a paragraph. New paragraphs, table rows and code blocks are refused with a notice, formatting applies directly, and source mode is unavailable while changes are pending.

## Who did what

- **Every comment, reply, suggestion and AI edit names its author**: you (set **Your Name** in Settings → General), or Prose with the model that wrote it.
- **Suggestions have a history.** Each one keeps its feedback and its outcome. Accepting and rejecting stay yours alone.
- **Activity shows a suggestion's whole life** (proposed, feedback, accepted or rejected) and filters by who made it.

## Fixes

- A chat turn with several tool steps no longer fails with a "thinking block" error on Anthropic.
- A click on text under the editor's dimmed selection is no longer lost.
