# Prose v1.10.0

Any model, any client, and every contribution has a name on it. Prose Agents now run on OpenAI and the Inference Cooperative's open-weight models as well as Anthropic, any MCP client can work on your open documents (including ChatGPT and claude.ai on the web), you can suggest changes yourself with Suggesting mode, and every comment, suggestion and AI edit records who made it.

## Models

- **OpenAI beside Anthropic.** Add an OpenAI key in Settings → LLM and pick a GPT model from the same list as the Claude models; the provider follows the model you pick. The status bar's model menu lists both.
- **One key per provider.** Each provider has its own key row with Test, Save and Clear. Keys are kept in the Keychain and used only by the app's main process.
- **Onboarding takes any of the keys.** A new install can verify an Anthropic key, an OpenAI key, an Inference Cooperative key or several, and chat works straight after.
- **The OpenAI list is GPT-5.5 and newer.** Any other model id can be typed under **Use custom model**.
- **Shorter menus, one way of naming.** Menus list each provider's flagship models; check more in Settings → LLM → Models in menus. The status bar shows a short name (Sonnet 5.5, Terra 6.1) and menus the full one (Claude Sonnet 5.5, OpenAI Terra 6.1).
- **A default model per mode.** Settings → LLM can give Chat, Editor and Create each a model; switching mode switches to it.
- **Switch model from the keyboard** with ⇧⌘M.
- **GPT models think and use tools together.** The thinking toggle works for GPT models that reason, and the reply shows a Thought process block when OpenAI provides one.
- **The Inference Cooperative.** Members can add their co-op key and use its open-weight models (DeepSeek, GLM and others, served from `gateway.inference.coop`) for chat and edits. Create a key at dashboard.inference.coop.
- An account with no credits now says so, instead of reading as "rate limited".
- Tab emoji work on any provider, using its small model (Claude Haiku, GPT-5 mini, DeepSeek). reMarkable handwriting recognition still uses your Anthropic key.

## Suggesting mode

- **Suggest instead of edit.** Click the pen button or **Editing** in the status bar. What you type is underlined, what you delete is struck through, and the file on disk keeps the original text until you accept.
- **One count for everything waiting on you.** The status bar shows a single suggestion count for your tracked changes and the AI's suggested edits; clicking it opens Quick Review.
- **Quick Review shows each change in its sentence**, so a deleted comma or an inserted word reads in context.
- **View controls.** The status bar's **All changes** menu can hide deletions or show the final text, and has Accept all and Reject all.
- Suggesting tracks text within a paragraph. New paragraphs, table rows and code blocks are refused with a notice, formatting applies directly, and source mode is unavailable while changes are pending.

## Who did what

- **Every comment, reply, suggestion and AI edit names its author**: you (set **Your Name** in Settings → General), Prose with the model that wrote it, or the connected client.
- **Suggestions have a history.** Leave feedback on a suggestion, and an agent can answer it and revise; the old version is kept as superseded. Accepting and rejecting stay yours alone.
- **Activity shows a suggestion's whole life** (proposed, feedback, revised, accepted or rejected) and filters by person or agent.

## MCP: any client

- **Connections.** Settings → Integrations → Connections gives each client its own named token that you can rename or revoke, with setup snippets for Claude Code, Codex, Open WebUI and LibreChat. Work done over a connection carries its name.
- **A Claude Desktop extension.** **Install Claude Desktop Extension** opens Claude Desktop's own install dialog and needs no Node.js on your Mac. The config-file install remains as a fallback.
- **Review tools for agents.** Agents can list suggestions, reply to your feedback, revise, read the review events, reply to and reopen comments, and propose tracked insertions and deletions.
- **Background documents.** Every document tool takes a `document`, so an agent can work on a tab you are not looking at, and MCP calls no longer move your caret, focus or tab.
- The server speaks MCP revisions 2025-11-25 and 2026-07-28, with titles, structured results and client-neutral instructions. Update the Claude Desktop integration when Prose offers it.

## Remote access for ChatGPT and claude.ai

- **Off until you turn it on**, in Settings → Integrations → Connections, and it needs you to be signed in. Your Mac accepts no incoming connections: Prose dials out to `api.prose.solo.ist`, which passes requests through without storing them.
- **You approve each assistant** on a Prose page in your browser, which shows what it asks to do: read, suggest edits, comment. Claude and ChatGPT are then connected and Prose tells you so; any other assistant waits for a second approval in Prose.
- **You stay in control.** Every connected assistant is listed in Prose, where you can change what it may do or remove it. Turning Remote access off cuts the connection at once.
- Remote assistants reach only the documents you have open. They can't open, create or list files, switch tabs, or accept a suggestion.

## Moving from the App Store edition

- If the App Store edition is installed, the first launch offers to **import its data**: projects, favorites, recent files, open tabs, comments, AI highlights and settings, and your API key if you choose. It copies, never moves, and is also available later from Settings → General.

## Fixes

- A chat turn with several tool steps no longer fails with a "thinking block" error on Anthropic.
- A click on text under the editor's dimmed selection is no longer lost.
- `revise_suggestion` works on a suggestion you rejected.
- The LibreChat setup snippet works on LibreChat 0.8.8.
- Claude Desktop's work is labelled "Claude Desktop", not "local-agent-mode-Prose".
- reMarkable credentials stay in the app's main process.
