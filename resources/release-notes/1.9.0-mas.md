# Prose v1.9.0

The polish release before the next big one. Every open tab keeps its own editor state, source mode is per tab and tells the truth, markdown round-trips as written, tables are editable, and a new install starts with one guided setup. The improvements from the releases since the last App Store version are listed at the end.

## Editor

- **Tabs keep your place.** Switching tabs no longer re-reads the document. Each tab holds its own editor state, so the caret, the scroll position, the undo history, comments and AI highlights are where you left them, and nothing typed in the half-second before a switch or a close is lost.
- **Source mode is per tab, and the text is the document while it is open.** Toggle to source in one tab, switch away and back: still in source mode, caret intact. Edits made in source mode are written back when you leave it, as one undo step. An untouched toggle changes nothing and does not mark the file dirty.
- **Comments and AI highlights stay on their text** through tab switches, relaunches, source-mode edits and AI replacements. They are re-anchored by their text, not by a stored position, and an AI edit over a commented passage moves the comment to the new text instead of resolving it.
- **Accepted or dismissed AI suggestions stay gone**, and chat edits land in the document they were asked about even if you switched tabs mid-reply.
- **Frontmatter edits are saved**, with autosave too; the block no longer flickers on repeated explorer clicks; bare dates such as `2026-05-02` stay as written.
- **The find bar follows the document.** Matches update as you edit, next and previous scroll the match into view, and the highlights clear when the bar closes.

## Markdown fidelity

- A `|` inside a table cell is escaped on save, so a cell can hold one and the row keeps every cell. Before, the overflow was silently dropped.
- Type a pipe table: a header row followed by its `| --- |` line becomes a table.
- A fenced code block indented inside a list item stays as written, and one that holds backticks gets a longer fence instead of closing early.
- Superscript and subscript write `^x^` and `~x~` rather than HTML tags.
- An image whose file name has spaces, which is every macOS screenshot, stays an image across saves.
- The AI's `edit` keeps bold, links and lists as it streams instead of landing them as literal markdown after the first chunk.

## Tables

- **Edit tables without leaving the editor.** Insert a table from the Edit menu, then use the `+` controls at the outer edges to append a row or column.
- Hover a row or column edge to reveal its grip; click the grip to select that row or column and open a small toolbar with move and delete. The rails hide while you type and follow a sidebar resize.
- Press Enter inside a cell for a line break instead of breaking the table apart. Every operation keeps the markdown a real pipe table rather than silently falling back to an HTML blob.
- The AI can read tables and change a cell, add a row or rewrite the whole table.

## Getting started

- **One first-run setup.** A new install walks through the AI choice, an API key that is verified before it is kept, and making Prose the default for markdown files, then lands on the home screen. Existing installs see nothing new; a change to the AI terms re-asks only that step.
- **A copy button on code blocks.**
- **Explorer:** cut and paste moves files, dragging onto `..` moves a file up a folder, and the open and save dialogs remember their last folder.
- **⌘⇧S is Save As** in the editor too, and "Back to activity" after resolving every comment lands on Activity.

## Fixes

- **Copying part of a bullet no longer carries the list marker.** The same fix covers blockquotes and headings.
- The suggestion popover follows the document as it scrolls.
- Updated the pinned Anthropic models, and fixed a request that the newest models rejected when extended thinking was switched off.
- The Dock icon follows the macOS 26 appearance modes, with the classic icon on earlier systems, and the Prose mark in About, on the home screen and as the AI avatar is the delivered artwork.

## Under the hood

- Electron 45, with the dependency sweep that clears the open security advisories. **Prose now needs macOS 13 or later.**

## Removed

- **The app-icon switcher.** Pilcrow is now the only icon, and a stored choice is migrated to it.
- **The "Stream agent edits" toggle.** Agent edits always animate now, still honouring your system's reduced-motion setting.

## New in this release

- **This window.** After an update, Prose shows what changed.

## Since the last App Store version

- **Your files are safer.** Prose notices when an open file changes on disk, from another editor, git or an agent. Clean tabs reload when you return to the window, and tabs with unsaved edits get a conflict prompt instead of overwriting the disk version, on save, autosave and relaunch. Relaunching no longer restores stale tab content over edits made while Prose was closed.
- **Comments are protected.** Adding a comment over a passage that already has one steers you to reply instead of replacing the thread, and deleting the text under the last open comment resolves it.
- **A blockquote button** in the selection toolbar.
- **Bullet marker preference:** choose `*` or `-` for bullet lists in Settings → Editor. Task lists always use `- [ ]`.
- Footnote references survive saving, and typing `[^1]` right after a word no longer leaves a stray `[`.
- The "Mark as AI-authored?" paste prompt keeps your cursor in place and can be dismissed for the session.
- Typing in the document while a review panel is open no longer triggers its shortcuts.
- ⌘F with the find bar already open selects the search text again, and ⌘- zooms out on macOS 26.
- **Explorer:** Duplicate in the right-click menu, with Finder-style names; switching folders clears the previous selection; opening a project right after launch shows the right folder.
- The AI's file tools skip hidden folders and only open text files.
