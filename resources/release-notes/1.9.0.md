# Prose v1.9.0

A quality-of-life release: tables are editable, Settings is smaller, and a few long-standing annoyances are gone.

## Tables

- **Edit tables without leaving the editor.** Insert a table from the Edit menu, then use the `+` controls at the outer edges to append a row or column.
- Hover a row or column edge to reveal its grip; click the grip to select that row or column and open a small toolbar with move and delete. Deletion sits behind an explicit selection rather than a bare `−`, so it is hard to do by accident.
- Press Enter inside a cell for a line break instead of breaking the table apart.
- Every operation keeps the markdown a real pipe table rather than silently falling back to an HTML blob.

## Fixes

- **Copying part of a bullet no longer carries the list marker.** Selecting a few words inside a list item and pasting into another app used to paste `* ected te`. The same fix covers blockquotes and headings.
- **The MCP "Update available" prompt now tracks the MCP surface, not the app version.** It stopped appearing on every release, and — more importantly — it now appears when the integration genuinely breaks. A config entry that lost its Prose server used to report itself as healthy.
- Updated the pinned Anthropic models, and fixed a request that the newest models rejected when extended thinking was switched off.

## Removed

- **The app-icon switcher.** Pilcrow is now the only icon, and a stored choice is migrated to it. This is the one change in this release that takes something away.
- **The "Stream agent edits" toggle.** Agent edits always animate now, still honouring your system's reduced-motion setting.
- **The Google Docs integration.** It was never functional in a shipped build — no credentials shipped and the flag was off, so it only ever showed "coming soon". Removing it drops a large dependency and real attack surface. The `google_doc_id` keys in your own markdown files are left untouched.
- The v1.2 appearance migration notice, which could appear on installs that never migrated anything.

## New in this release

- **This window.** After an update, Prose now shows what changed, and offers to update the Claude Desktop MCP integration when that integration actually changed.
